# Personal Portfolio Website

## Project Description
This is a personal portfolio website created using HTML and CSS. It showcases personal information, skills, education, goals, and contact details through a simple and clean design.

## Features

- **Home Page:** Introduces the portfolio owner and displays a profile image.
- **About Page:** Provides personal information, education, interests, and career goals.
- **Contact Page:** Includes a contact form with name, email, subject, and message fields.
- **Navigation Bar:** Allows users to move between Home, About, and Contact pages.
- **Responsive Design:** Adjusts the layout for mobile and tablet screens.
- **Hover Effects:** Adds interactive visual effects to buttons, navigation links, and cards.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Navigate between Home, About, and Contact pages using the navigation bar.
